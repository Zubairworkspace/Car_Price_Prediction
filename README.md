# 🚗 Car Price Prediction Using Machine Learning

## Try free demo at: 
https://carpriceprediction-bmuzm4qqcff2ggmepzdfdf.streamlit.app/


## 📌 Project Overview

This project predicts the selling price of used cars using Machine Learning regression algorithms.

The project includes:

- Data Cleaning
- Exploratory Data Analysis
- Feature Engineering
- Data Preprocessing
- Multiple Regression Models
- Model Evaluation
- Cross Validation
- Feature Importance
- Model Saving
- Streamlit Deployment

---

## 📊 Dataset

The dataset contains information about used cars.

### Features

- Car_Name
- Year
- Present_Price
- Driven_kms
- Fuel_Type
- Selling_type
- Transmission
- Owner

### Target

- Selling_Price

## 🤖 Machine Learning Models

The following regression models are compared:

1. Linear Regression
2. Random Forest Regression
3. Gradient Boosting Regression
4. Extra Trees Regression

The model with the best R² score is automatically selected.
